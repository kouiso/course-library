# 案内文のひな形

教材を受け取る人に送る案内文のひな形です。`{{...}}`の所に、送る人が本物の値を入れて使います。
本物のURL・ID・パスワード・合言葉・連絡先は、このリポジトリには書きません。

入れる値の一覧:

| 差し込み口 | 入れる物 |
| --- | --- |
| `{{URL}}` | 教材の入口のURL |
| `{{BASIC_ID}}` | 入口で最初に聞かれるID |
| `{{BASIC_PASSWORD}}` | 入口で最初に聞かれるパスワード |
| `{{PHRASE}}` | 教材ごとの合言葉 |
| `{{PRODUCT_NAME}}` | 商品の名前 |
| `{{CONTACT}}` | うまくいかない時の連絡先 |

入口では、画面が2回出ます。1回目はブラウザの小さなダイアログ（IDとパスワード）、2回目は教材のページの合言葉です。
2つは別の物なので、案内文でも別々に書きます。

## 1. 購入者向け（初めて受け取る人）

件名: {{PRODUCT_NAME}}の教材をお渡しします

{{PRODUCT_NAME}}をご購入いただき、ありがとうございます。
教材は、次の順番で開いてください。

1. 次のURLを開きます。
   {{URL}}
2. ブラウザの小さな画面で、IDとパスワードを聞かれます。次を入れてください。
   - ID: {{BASIC_ID}}
   - パスワード: {{BASIC_PASSWORD}}
3. 教材のページで、合言葉を聞かれます。次を入れてください。
   - 合言葉: {{PHRASE}}
4. 一覧から{{PRODUCT_NAME}}を選び、ファイルを保存します。

うまくいかない時:
- 2.の画面が消えて「認証が必要です」と出たら、「入口へ戻る」を押して、2.からやり直してください。
- 3.で「合言葉を確認して、もう一度入力してください」と出たら、前後に空白が入っていないか見てください。続けて間違えると、1分ほど入力できなくなります。
- それでも開けない時は、下の連絡先へ、どの手順で止まったかを書いてお知らせください。パスワードや合言葉は書かないでください。

連絡先: {{CONTACT}}

## 2. 購入者向け（すでに別の教材をお持ちの人）

件名: {{PRODUCT_NAME}}を追加でお渡しします

{{PRODUCT_NAME}}をご購入いただき、ありがとうございます。
すでにお渡ししているURLとIDとパスワードは、そのままお使いいただけます。今回は合言葉だけが新しくなります。

1. これまでと同じURLを開きます。
   {{URL}}
2. ブラウザの小さな画面では、これまでのIDとパスワードを入れてください。
3. 教材のページで、次の合言葉を入れてください。
   - 合言葉: {{PHRASE}}
4. 一覧から{{PRODUCT_NAME}}を選び、ファイルを保存します。

うまくいかない時:
- IDやパスワードを忘れた時は、下の連絡先へお知らせください。
- 一覧に{{PRODUCT_NAME}}が出ない時は、今回の合言葉を入れたかを確かめてください。前の教材の合言葉では、今回の教材は開きません。
- それでも開けない時は、どの手順で止まったかを書いてお知らせください。パスワードや合言葉は書かないでください。

連絡先: {{CONTACT}}

## 3. アンケート回答者向け

件名: アンケートへのご回答ありがとうございます（プレゼント教材のご案内）

アンケートにお答えいただき、ありがとうございます。
プレゼントの教材は、次の順番で開いてください。

1. 次のURLを開きます。
   {{URL}}
2. ブラウザの小さな画面で、IDとパスワードを聞かれます。次を入れてください。
   - ID: {{BASIC_ID}}
   - パスワード: {{BASIC_PASSWORD}}
3. 教材のページで、合言葉を聞かれます。次を入れてください。
   - 合言葉: {{PHRASE}}
4. 一覧から教材を選び、ファイルを保存します。次回からは、このURLをブックマークしておくと便利です。

うまくいかない時:
- 2.の画面が消えて「認証が必要です」と出たら、「入口へ戻る」を押して、2.からやり直してください。
- 3.で入れない時は、前後に空白が入っていないか見てください。続けて間違えると、1分ほど入力できなくなります。
- それでも開けない時は、下の連絡先へ、どの手順で止まったかを書いてお知らせください。

連絡先: {{CONTACT}}
